## 🎯 Common Questions & Answers

**Q: Where's the code?**
A: Main code files are in `lib/`:
- Controllers: `lib/controllers/auth_controller.dart`
- Screens: `lib/screens/login_screen.dart`, `lib/screens/signup_screen.dart`
- Config: `lib/main.dart`

**Q: How do I start the app?**
A: See [DEV_COMMANDS_REFERENCE.md - Running](DEV_COMMANDS_REFERENCE.md#running-the-app)

**Q: Where's the Firebase configuration?**
A: See `lib/firebase_options.dart` (auto-generated) and firebase setup in `lib/main.dart`
